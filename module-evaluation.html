Module 3

GenAI evaluating and comparing models

Learn to compare model outputs using factuality, usefulness, hallucination checks, clinical safety, and uncertainty.

AppliedFactuality, hallucination, usefulness, uncertainty, safety, comparison rubricReliability, accountability, non-maleficence

Learning outcomes

  • Evaluate outputs for factuality, relevance, completeness, uncertainty, and clinical safety.
  • Compare two model responses using a structured rubric.
  • Recognise hallucination, citation failure, hidden bias, and unsupported clinical claims.

Teaching activities

  • Score two AI answers with a rubric.
  • Find missing safety warnings in a generated response.
  • Build a model comparison table for a teaching scenario.

Assessment

Document why one AI response is safer than another.

Ethics focus

Reliability, accountability, non-maleficence
